# Triage labels

Use these exact role and label names:

| Role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue. |
| needs-info | needs-info | Waiting for information needed to proceed. |
| ready-for-agent | ready-for-agent | Fully specified agent work, subject to blocking dependencies. |
| ready-for-human | ready-for-human | Requires human implementation, assessment, or physical captures. |
| wontfix | wontfix | Will not be actioned. |

Inspect existing labels before creating missing ones. Do not rename or
overwrite unrelated labels. These mappings can be edited if the repository's
workflow changes.
